# Digital Compass
Digital Compass started from seeing my grandmother struggle to tell AI-generated videos apart from real ones. It made me think about how older adults experience the digital world and the importance of making it easier and safer to navigate.

## Features
Digital Compass has a character named Juan who guides users through different activities based on situations they might encounter online. These activities include topics like deepfakes, online scams, privacy, and digital well-being, helping users learn how to recognize risks and make better decisions.

## Language
Digital Compass was originally created in Spanish for older adults in my community in Colombia. Later, I added an English translation, so the content is now available in both languages.

## Tecnologies Used
I used HTML, CSS, and JavaScript.

## Project Status
Digital Compass is the first version of something I'd like to keep building and improving. Some features are already working, but there are still things I'd like to change or add. I want to keep working on it as I learn more about programming and come up with new ideas for the project.
